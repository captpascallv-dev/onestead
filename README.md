# Onestead has moved

Onestead is now part of [agent-baton](https://github.com/captpascallv-dev/agent-baton), in the [`onestead/`](https://github.com/captpascallv-dev/agent-baton/tree/main/onestead) directory. Its full commit history moved with it, and it is still licensed under Apache-2.0.

This repository is archived and read-only. New releases, issues and pull requests go to agent-baton.

Install from the new location:

```
git clone https://github.com/captpascallv-dev/agent-baton
python -m pip install ./agent-baton/onestead
```

The last version published here is the 2026-11-02 release (`ddf01d7`).
