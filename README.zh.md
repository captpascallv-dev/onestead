# Onestead 已经搬家

Onestead 现在是 [agent-baton](https://github.com/captpascallv-dev/agent-baton) 的一部分，在 [`onestead/`](https://github.com/captpascallv-dev/agent-baton/tree/main/onestead) 目录下。完整的提交历史一起搬了过去，许可证仍是 Apache-2.0。

这个仓库已归档，只读。以后的新版本、问题反馈和合并请求请到 agent-baton。

从新地址安装：

```
git clone https://github.com/captpascallv-dev/agent-baton
python -m pip install ./agent-baton/onestead
```

这里最后发布的是 2026-11-02 那一版（`ddf01d7`）。
